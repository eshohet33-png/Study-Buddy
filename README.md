# Study Buddy

A lightweight React + Vite homework planner.

## Run locally
1. Install Node.js.
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`

## Deploy to Vercel
1. Upload this project to a GitHub repository.
2. Sign in to Vercel and choose **Add New → Project**.
3. Import the GitHub repository.
4. Vercel should detect Vite automatically. Build command: `npm run build`; output directory: `dist`.
5. Click **Deploy**. Vercel will provide a shareable `*.vercel.app` address.
6. To choose a project address, open **Settings → Domains** and enter an available name such as `study-buddy-yourname.vercel.app`.

Assignments are stored in the browser's local storage on each device. This first version does not sync data between different users or devices.
